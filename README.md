# Git 练习仓库

这是《Git 零基础入门教程》的练习仓库，欢迎参加本项目，提交前请先阅读下方的说明。

## 这个仓库是做什么的

它专门用来练习《实战三：参与开源项目 + 课程总结》里的流程：Fork、克隆、开分支、改一处、推到自己的 Fork、向这里开 PR、按审查意见修改、被合并、同步回自己的 Fork。这里的 PR 会由课程方审查并合并；改错了也没有关系，这就是练习的目的。

## 练习内容

1. 把上面那句话里的错别字“说名”改成“说明”。如果你打开时它已经被上一位读者改好了，课程方会尽快把它改回来，你也可以直接做第 2 条。
2. 在下面“参与者”一节的列表末尾加上你的名字，一行 `- 你的名字`。
3. 可选：先到 Issues 里开一个 Issue，再在提交说明或 PR 描述里写 `Fixes #编号`，PR 合并后看它被自动关闭。

每一步怎么做，见 [CONTRIBUTING.md](CONTRIBUTING.md)。
